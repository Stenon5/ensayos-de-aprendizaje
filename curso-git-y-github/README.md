# Curso de Git y GitHub

Práctica del curso de Git y GitHub de Platzi. El curso usa un blog de ejemplo, Hyperblog, que creó el equipo de Platzi. Este repositorio nació como fork de [freddier/hyperblog](https://github.com/freddier/hyperblog).

## Qué hice

- Seguí el curso, que enseña los comandos de Git (commits, ramas, merges y tags) y el flujo de trabajo de GitHub.
- Hice un fork del blog del curso para practicar en mi propia copia.
- Al terminar agregué mi nombre a la lista de estudiantes en `blogpost.html`.

## Archivos

- `blogpost.html`, `css/` e `imagenes/`: el blog de ejemplo.
- `historia.txt`: archivo de texto para practicar cambios y conflictos.
- `README-original.md`: el README original del curso, que es una broma a propósito.

## Cómo verlo

Abre `blogpost.html` en el navegador.
