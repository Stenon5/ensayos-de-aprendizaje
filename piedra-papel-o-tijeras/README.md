# Piedra, papel o tijeras

Proyecto olvidado de mis primeros pasos con Python (noviembre de 2022 a abril de 2023). Empezó como un juego simple siguiendo lo que enseñaban en clases y videos, y después lo reorganicé. El README que tenía está en `README-original.md`.

## Qué hice

- Un juego contra la computadora, al mejor de 3 rondas.
- Una segunda versión que separa el programa en funciones, una por jugada y otra para llevar el marcador. El commit la llama paso a programación orientada a objetos, aunque no llegó a usar clases.

## Cómo usarlo

```sh
python3 main.py
```

Elige piedra, papel o tijeras en cada ronda.
