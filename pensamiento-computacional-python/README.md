# Pensamiento computacional con Python

Ejercicios olvidados de un curso de pensamiento computacional con Python. Los fui escribiendo mientras seguía las clases, así que algunos quedaron a medio hacer.

## Qué hice

- `python/pensamiento_comp/`: búsqueda de raíces por enumeración, por aproximación y por búsqueda binaria, factoriales, manejo de excepciones y pruebas de caja negra y de caja blanca con `unittest`.
- `python/Algoritmos+POO/`: medición del tiempo de algoritmos y un ejemplo de complejidad cuadrática.
- `Algoritmos/`: un borrador de ordenamiento de burbuja, incompleto, y otra versión de la aproximación.

## Cómo usarlo

Cada archivo se ejecuta solo:

```sh
python3 python/pensamiento_comp/busqueda_binaria.py
```

Las pruebas se corren con:

```sh
python3 -m unittest python/pensamiento_comp/caja_negra.py
```
