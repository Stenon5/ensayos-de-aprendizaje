# Ensayos de aprendizaje

Aquí guardo las prácticas que hice mientras aprendía herramientas nuevas. Son proyectos olvidados que armé para seguir lo que enseñaban distintos cursos, clases y videos. Quedan como un pequeño registro de lo que estudié, no como proyectos terminados ni pensados para uso de otros.

| Carpeta | Qué practiqué |
|---|---|
| [curso-git-y-github](curso-git-y-github/) | Comandos de Git y el flujo de trabajo de GitHub, con el blog de ejemplo del curso de Platzi |
| [base-de-datos-mysql](base-de-datos-mysql/) | Una base de datos para un blog en MySQL Workbench |
| [piedra-papel-o-tijeras](piedra-papel-o-tijeras/) | Mis primeros pasos con Python: un juego contra la computadora |
| [curso-jenkins](curso-jenkins/) | Trabajos y pipelines del curso de Jenkins de Platzi |
| [pensamiento-computacional-python](pensamiento-computacional-python/) | Algoritmos de búsqueda, aproximación y pruebas con Python |
| [curso-python-pip](curso-python-pip/) | pip, entornos virtuales, pandas, gráficos, FastAPI y Docker con Python |
| [pruebas-con-playwright](pruebas-con-playwright/) | Primeros pasos para automatizar el navegador con Playwright |

Cada carpeta tiene su propio README con lo que hice y cómo usarlo.
